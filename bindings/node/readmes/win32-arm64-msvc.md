# @0xdoublesharp/bin-packing-win32-arm64-msvc

Native Node.js binary for **Windows ARM64 (MSVC)**, used by
[`@0xdoublesharp/bin-packing`](https://www.npmjs.com/package/@0xdoublesharp/bin-packing),
a Rust-powered optimizer for 1D cutting stock, 2D sheet packing, 3D box packing,
and irregular nesting.

The main package installs this binary automatically on matching systems. Install
the main package to use the JavaScript API and TypeScript types:

```sh
npm install @0xdoublesharp/bin-packing
```

See the [main package README](https://github.com/0xdoublesharp/bin-packing/blob/main/bindings/node/README.md)
for usage and API details, or the [project README](https://github.com/0xdoublesharp/bin-packing/blob/main/README.md)
for a library overview.

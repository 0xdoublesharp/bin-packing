# v0.6.1

Refresh dependency security fixes, native npm documentation, and release tooling.
Solver APIs, packing models, and search policies are unchanged.

## Changes

- Add concise READMEs for all six native npm packages, describing each platform,
  automatic binary installation, and links to the main package and project
  documentation. Package preparation copies these READMEs into release archives.
- Update compatible Rust dependencies in the workspace and fuzzing lockfiles.
  Resolve the crossbeam-epoch advisory, update rand to a patched release, and
  remove the affected anyhow dependency. Require rand 0.9.3 or newer in the
  0.9 series for Rust consumers.
- Update the native build CLI to 3.10.12 and js-yaml to 5.5.0, resolving the
  reported YAML parsing denial-of-service advisories.
- Update pnpm to 10.34.9 to resolve package-manager security advisories, npm to
  11.21.2 for publishing, and Playwright to 1.65.0 for browser verification.
- Pin Rust 1.99.1 while retaining the minimum supported Rust version of 1.99.
- Use the transferred `0xdoublesharp/bin-packing` repository in package metadata
  and documentation. Publish the Rust crate with crates.io trusted publishing,
  obtaining a short-lived token before any package is published.
- Pin release-note links to the matching Git tag so they work in GitHub release
  bodies. Add regression tests for link resolution and repository containment.

## Compatibility and verification

The Rust crate, Node.js package, WASM package, and six native platform packages
use version 0.6.1. Existing APIs and the Node.js engine requirement of 18 or newer
are unchanged. Native package installation continues through
`@0xdoublesharp/bin-packing`.

Local verification covers the quality gate, isolated Rust/WASM features and fuzz
project, native/WASM package archives, TypeScript declarations, documentation
examples, generated solver cases, and Chromium contracts on macOS ARM64.
Both Rust lockfiles pass `cargo audit --deny warnings`; npm dependency and updated
CI-tool advisory checks report no known vulnerabilities.

The release workflow separately builds all six native targets and gates
publication on its quality and consumer checks. See the
[release runbook](https://github.com/0xdoublesharp/bin-packing/blob/v0.6.1/docs/releasing.md) and [testing guide](https://github.com/0xdoublesharp/bin-packing/blob/v0.6.1/docs/testing-confidence.md).

# v0.6.2

Add a pinned Lean 4 formal verification suite covering packing certificates,
lower bounds, exact optimization claims, physical cutting and loading,
irregular geometry, and production Rust/Node/WebAssembly MIR refinement proofs.
Public solver APIs, packing models, and search policies are unchanged.

## Changes

- Add 22 Lean 4 proof modules under `proofs/` (no Mathlib dependency) and 48
  `--verify` certificate tags covering 1D/2D/3D ordinary and constrained
  packing, full material/waste/cost accounting, 2D/3D dual-feasible-function
  lower bounds, explicit optimization objectives and tie-breakers, exact
  count/cost/knapsack/open-dimension optimality, non-allocating oversize and
  inventory infeasibility witnesses, staged cut trees, workpiece-aware saw
  schedules, saw-verified reusable offcuts, 1D/2D legacy cut plans, 3D stack
  loading and axle reactions, and irregular circles, polygons, orthogonal and
  sloped shapes with positive clearance, rigid transforms, and curved arcs.
- Route shared production arithmetic checks (`end_with_gap_at_most`,
  `effective_axis_bound`, `fits_trimmed_axis`, `area_u64`, `scale_threshold`,
  `scale_floor`, and the Node/WASM `is_safe_js_integer` / `is_safe_js_sum`
  guards) through pure helpers verified directly from dev and release `rustc`
  MIR in Lean.
- Add `./scripts/check-proofs.sh` (with `--verify` and `--bindings` modes) and
  a `--audit-tcb` check that blocks proof escapes and non-allowlisted
  `set_option` directives, enforces kernel typechecking, kernel-audits every
  local Lean theorem against Lean's standard axioms (`propext`, `Quot.sound`,
  `Classical.choice`), verifies pinned Rust and Lean toolchains, and emits
  lockfile SHA-256 digests.
- Add 287 end-to-end Rust certificate cases in
  `crates/bin-packing/tests/lean_certificates.rs` and 145 Node/WebAssembly
  certificate cases in `bindings/test/lean-certificates.cjs`, including
  adversarial forgery, rounding-boundary, blade-strip, and topology rejections.
- Update the top-level README, contributor guide, workspace verification guide,
  and testing guide to document the Lean verification commands, `--verify`
  contract, exact binary64 dyadic pricing domain, and stated trusted computing
  base.

## Compatibility and verification

The Rust crate, Node.js package, WASM package, and six native platform packages
use version 0.6.2. Existing Rust, Node.js, and WebAssembly APIs, the MSRV of
1.99, and the Node.js engine requirement of 18 or newer are unchanged.

Local verification on macOS ARM64 covers `./scripts/check-quality.sh`,
`./scripts/check-features.sh`, `./scripts/check-proofs.sh`,
`./scripts/check-proofs.sh --bindings`, `cargo package -p bin-packing --locked`,
and native/WebAssembly package builds, archives, smoke/contract suites, and
documentation examples. TypeScript declaration compilation, Chromium browser
checks, and native binaries for the remaining five targets run in the CI and
tag release workflow.

See the [release runbook](https://github.com/0xdoublesharp/bin-packing/blob/v0.6.2/docs/releasing.md) and
[testing guide](https://github.com/0xdoublesharp/bin-packing/blob/v0.6.2/docs/testing-confidence.md).
